• Hypertext Markup Language (HTML) is the standard markup language for documents designed to be displayed in a web browser. It defines the content and structure of web content.

  • It enables the separation of content from presentation, controlling layout, colors, and fonts. CSS is rule-based: styles are defined by rules with selectors and declarations. This separation enhances content accessibility and simplifies document structure.

  • JavaScript is a dynamic programming language widely used for web development, enabling the creation of interactive and dynamic web pages. It is a single-threaded, synchronous language that is interpreted by web browsers, making it highly accessible and versatile 1. JavaScript is loosely typed, meaning variable types are determined at runtime

  • React JS, commonly referred to as React, is a JavaScript library developed by Facebook for building user interfaces (UIs). It is particularly well-suited for creating dynamic and interactive web applications. React is a declarative, component-based library that allows developers to build reusable UI components

  • Node.js is an open source server environment. Node.js is free. Node.js runs on various platforms (Windows, Linux, Unix, Mac OS X, etc.). Node.js uses JavaScript on the server.
